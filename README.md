# 🐾 PetRa - Pet Adoption Platform

## 📌 Project Name
**PetRa**

---

## 🎯 Purpose
PetRa is a modern pet adoption web platform designed to connect loving homes with rescued and adoptable pets.  
The goal is to make the adoption process simple, transparent, and accessible for everyone while promoting animal welfare.

---

## 🌐 Live URL
https://petra-orpin.vercel.app/

---

## ✨ Features

- 🐶 Browse available pets with images and detailed information
- 📝 Easy and secure pet adoption request system
- ❤️ Featured pets section to highlight adoptable animals
- 🏡 User-friendly dashboard for managing adoptions
- 🔍 Filter and search pets by category, breed, or type
- 📱 Fully responsive design for mobile, tablet, and desktop
- 🔐 Authentication system for safe user access
